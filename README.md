# Project 2 - Exploratory Data Analysis (EDA)

## 📌 Overview

This project is part of the Data Analytics Industrial Training program.

The objective of this project is to perform Exploratory Data Analysis (EDA)
on the cleaned e-commerce dataset.

EDA is used to understand patterns, trends, distributions, relationships,
and unusual observations within a dataset.

## 🎯 Objective

The main goals of this project are:

- Calculate basic statistics
- Understand numerical distributions
- Analyze categorical variables
- Identify trends
- Detect potential outliers
- Analyze product performance
- Analyze customer behavior
- Summarize important observations

## 📊 Dataset

The cleaned dataset contains:

- 1,200 orders
- 1,189 unique customers
- 7 unique products
- 14 columns

## 🛠️ Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📈 EDA Process

### 1. Dataset Overview

The dataset was loaded using Pandas and examined using:

- `shape`
- `head()`
- `info()`
- `describe()`

### 2. Basic Statistics

Basic descriptive statistics were calculated for numerical columns:

- Quantity
- UnitPrice
- ItemsInCart
- TotalPrice

The analysis included:

- Count
- Mean
- Median
- Minimum
- Maximum
- Standard deviation

### 3. Overall Dataset Statistics

The following results were obtained:

| Metric | Value |
|---|---:|
| Total Orders | 1,200 |
| Unique Customers | 1,189 |
| Unique Products | 7 |
| Total Revenue | 1,264,761.96 |
| Average Order Value | 1,053.9683 |
| Median Order Value | 823.615 |
| Highest Order Value | 3,456.40 |

### 4. Product Analysis

Product-level analysis was performed to identify:

- Number of orders by product
- Total quantity sold
- Revenue generated by product
- Average unit price
- Average order value

This helps identify high-performing products.

### 5. Payment Method Analysis

The frequency of different payment methods was analyzed.

The observed payment methods include:

- Online
- Cash
- Credit Card
- Debit Card
- Gift Card

The most frequently used payment method was:

**Online — 258 orders**

### 6. Order Status Analysis

Order statuses were analyzed to understand the distribution of orders.

The statuses include:

- Cancelled
- Returned
- Pending
- Shipped
- Delivered

The most common status was:

**Cancelled — 250 orders**

### 7. Referral Source Analysis

Referral sources were analyzed to understand where orders originated.

The referral sources include:

- Instagram
- Email
- Google
- Facebook
- Referral

The highest order count was associated with:

**Instagram — 259 orders**

### 8. Coupon Analysis

Coupon usage was analyzed to identify the frequency of different coupon
codes.

The dataset contains four coupon categories:

- FREESHIP
- No Coupon
- WINTER15
- SAVE10

### 9. Customer Analysis

Customer-level analysis was performed to identify:

- Customers with multiple orders
- Customers with the highest number of orders
- Customers generating the highest revenue

### 10. Time-Based Analysis

The `Date` column was converted into datetime format and used to analyze
monthly trends.

Monthly analysis included:

- Monthly order count
- Monthly revenue
- Revenue trends over time

### 11. Outlier Detection

Potential outliers in `TotalPrice` were identified using the
Interquartile Range (IQR) method.

The method uses:

```text
IQR = Q3 - Q1

Lower Bound = Q1 - 1.5 × IQR

Upper Bound = Q3 + 1.5 × IQR
